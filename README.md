# Кузница Кальрадия

Веб-приложение для онлайн-каталога средневековых доспехов и реконструкторского снаряжения с панелью управления мастерской, приёмом заявок через Яндекс.Формы и интеграциями с ВКонтакте и Telegram.

## Архитектура

**Тип:** Клиент-серверное SPA (Single Page Application)

| Слой | Технология |
|------|-----------|
| Фронтенд | React 18 + TypeScript, Vite, Lucide Icons |
| Бэкенд | Python 3.12, Django 5.x, Django REST Framework |
| База данных | PostgreSQL |
| Веб-сервер | Nginx + Gunicorn |
| Развёртывание | Timeweb Cloud VPS (Ubuntu 24.04) |

```
┌──────────────────────────────────────────────────────┐
│                      Браузер                         │

           ▼                           ▼
```

## Функциональные модули

### 1. Каталог товаров
- Фильтрация по категории, материалу, эпохе, размеру и статусу (фильтры в сворачиваемом меню)
- Полнотекстовый поиск по названию
- Сортировка по цене и популярности
- Детальная карточка: галерея, историческая справка, характеристики, лайтбокс для просмотра фото
- Каталог комплектов (`ProductSet`) с ценой со скидкой и переходом к отдельным предметам

### 2. Панель управления мастерской
Доступна авторизованным сотрудникам (`is_staff`). Состоит из вкладок:

| Вкладка | Описание |
|---------|---------|
| **Сводка** | Счётчики заказов по статусам, дедлайны на 14 дней вперёд, предупреждения о малом запасе |
| **Заказы** | Канбан-доска (Новый / В работе / Выполнен / Отменён), быстрая смена статуса, форма создания заказа с автозаполнением цены и аванса (50%) |
| **Задачи** | Стек доступных задач (фильтруется по допускам мастера) и личные взятые задачи |
| **Клиенты** | Поиск, просмотр и редактирование клиентов |
| **Допуски** | Управление допусками мастеров к конкретным предметам (только суперадмин) |
| **Каталог** | Создание, редактирование и удаление товаров |

### 3. Система задач
- Администратор создаёт заказ (предмет / комплект / услуга)
- При заказе комплекта автоматически создаются задачи по каждому предмету в нём
- Мастер видит в стеке только задачи по предметам, к которым у него есть допуск
- Мастер берёт задачу → она переходит в «Мои задачи» → отмечает выполненной
- Email-уведомления за 14, 7, 3 и 1 день до дедлайна (ответственному и администратору)

### 4. Приём заявок
- Интеграция с Яндекс.Формами через webhook (`/api/webhook/client-order/`)
- Автоматическое создание записей клиентов и заказов в БД
- Поддержка нестандартного формата Яндекс.Форм (JSON-объекты в теле запроса)

### 5. Автопубликация
- Приём новых постов со стены ВКонтакте через Callback API (`wall_post_new`)
- Сохранение публикаций в БД (модель `VKPost`) и отображение в блоке новостей на сайте
- Автоматический репост в Telegram-канал через бота

## Модели данных

| Модель | Назначение |
|--------|-----------|
| `Product` | Товар каталога |
| `ProductSet` | Комплект из нескольких товаров (со скидочной ценой) |
| `Review` | Отзыв на товар |
| `Client` | Клиент мастерской |
| `Order` | Заказ (предмет / комплект / услуга) |
| `Task` | Задача в стеке (создаётся автоматически при заказе) |
| `MasterApproval` | Допуск мастера к конкретному предмету |
| `VKPost` | Пост из ВКонтакте |
| `Colleague` | Сотрудник мастерской |
| `Material` | Материал (справочник, управляется через Django Admin) |
| `IntegrationLink` | Внешние ссылки (VK, Telegram, Яндекс.Форма) |

## Локальная разработка

### Требования

- Python 3.11+
- Node.js 20+

### Запуск

**1. Backend:**

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # заполнить при необходимости
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Backend доступен по адресу `http://127.0.0.1:8000`.

**2. Frontend (в отдельном терминале):**

```bash
npm install
npm run dev
```

Frontend с горячей перезагрузкой: `http://localhost:5173`.
API-запросы проксируются на Django автоматически.

### Тесты

```bash
python manage.py test workshop
```

### Проверка уведомлений о горящих заказах

```bash
python manage.py notify_urgent_orders --dry-run
```

## Настройка интеграций

### ВКонтакте → Telegram

1. Создать бота в @BotFather, добавить в Telegram-канал с правом публиковать.
2. Прописать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID`.
3. В настройках группы ВК → **Работа с API → Callback API** добавить сервер:
   - URL: `https://your-domain.com/api/integrations/vk/callback/`
   - Тип событий: `Новая запись на стене`
4. Прописать `VK_CONFIRMATION_TOKEN` и `VK_CALLBACK_SECRET`.

### Допуски мастеров

1. Войти в панель управления под суперадмином.
2. Открыть вкладку **Допуски**.
3. Для каждого мастера отметить галочками предметы, которые он может изготавливать.
4. После настройки мастер будет видеть в стеке задач только подходящие ему задачи.
