# ТЕРМИНЫ И СОКРАЩЕНИЯ

**API** (Application Programming Interface) — программный интерфейс приложения; совокупность правил и протоколов, определяющих способ взаимодействия программных компонентов между собой.

**Backend (бэкенд)** — серверная часть веб-приложения, отвечающая за обработку запросов, бизнес-логику и работу с базой данных.

**Callback API** — механизм уведомления сервера о событиях путём отправки HTTP-запроса на заранее настроенный URL при возникновении события во внешней системе.

**CORS** (Cross-Origin Resource Sharing) — механизм, позволяющий или запрещающий веб-приложениям одного домена выполнять запросы к ресурсам другого домена.

**CSRF** (Cross-Site Request Forgery) — вид атаки, при которой вредоносный сайт заставляет браузер аутентифицированного пользователя выполнить нежелательный запрос к доверенному сайту.

**CRUD** (Create, Read, Update, Delete) — четыре базовые операции с данными: создание, чтение, изменение и удаление.

**DRF** (Django REST Framework) — расширение фреймворка Django для разработки REST API.

**Frontend (фронтенд)** — клиентская часть веб-приложения, выполняемая в браузере пользователя.

**GUI** (Graphical User Interface) — графический пользовательский интерфейс.

**HMR** (Hot Module Replacement) — технология замены изменённых модулей в браузере без полной перезагрузки страницы.

**JSON** (JavaScript Object Notation) — текстовый формат обмена данными, основанный на синтаксисе JavaScript-объектов.

**ORM** (Object-Relational Mapping) — технология преобразования данных между реляционной СУБД и объектно-ориентированной программой.

**REST** (Representational State Transfer) — архитектурный стиль создания распределённых гипермедиа-систем, ориентированный на работу с ресурсами через стандартные HTTP-методы.

**SPA** (Single Page Application) — одностраничное приложение; веб-приложение, которое при первом запросе загружает одну HTML-страницу и в дальнейшем обновляет её содержимое динамически, без полной перезагрузки.

**WSGI** (Web Server Gateway Interface) — стандарт взаимодействия между веб-сервером и Python-приложением.

**VPS** (Virtual Private Server) — виртуальный выделенный сервер.

**БД** — база данных.

**ВКР** — выпускная квалификационная работа.

**ПЗ** — пояснительная записка.

**ПО** — программное обеспечение.

**СУБД** — система управления базами данных.

**ТЗ** — техническое задание.
