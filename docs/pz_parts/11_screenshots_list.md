# СПИСОК НЕОБХОДИМЫХ СКРИНШОТОВ ПРОДУКТА

Ниже приведён перечень скриншотов системы, которые необходимо сделать для включения в пояснительную записку. Для каждого скриншота указаны: номер рисунка, место размещения в тексте, что должно быть видно на экране и рекомендуемое разрешение.

---

## Скриншот 1 — Главная страница: полный каталог
**Номер рисунка:** Рисунок 9  
**Место в тексте:** Раздел 2.1.3.1  
**URL:** http://109.107.171.134:8080/  
**Что должно быть видно:**
- Шапка сайта с названием «Кузница Кальрадия» и навигацией
- Панель фильтров слева (фильтры по категории, периоду, материалу)
- Сетка карточек товаров (минимум 6 карточек)
- На одной из карточек — значок скидки (если товар входит в комплект)
- Строка поиска
**Разрешение:** 1440×900, fullpage или viewport  
**Примечание:** Снимать на Desktop-разрешении
