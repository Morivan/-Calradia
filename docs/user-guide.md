## 1. Публичный каталог

Главная страница сайта открыта для всех посетителей без авторизации.

### Навигация и фильтрация

В левой панели находятся фильтры каталога:

| Фильтр | Описание |
|--------|----------|
| **Категория** | Шлемы, Нагрудники, Полные комплекты, Щиты и др. |
| **Материал** | Сталь, Кожа, Комбинированный и др. |
| **Эпоха** | XIII–XVI вв. |
| **Размер** | XS, S, M, L, XL |
| **Статус** | В наличии / Изготовим на заказ / Снят с производства |

Можно выбрать несколько значений в одном фильтре. Кнопка **Сбросить** в правом верхнем углу панели фильтров удаляет все выбранные условия.

### Поиск

Поле поиска в верхней части страницы выполняет фильтрацию по названию товара в реальном времени.

### Сортировка

Кнопки над сеткой товаров:

- **По умолчанию** — порядок добавления
- **Сначала новые** — по дате добавления
- **Популярные** — по рейтингу популярности
- **Срок изготовления** — от коротких к длинным

### Комплекты

Комплекты отображаются в отдельном разделе под основным каталогом. В карточке комплекта показана цена при отдельной покупке, цена комплекта и экономия. Нажатие на товар внутри комплекта открывает его карточку.

## 2. Карточка товара

Открывается при клике на любой товар в каталоге.

### Галерея

- Нажатие на главное изображение открывает **лайтбокс** — увеличенный просмотр во весь экран.
- Закрыть лайтбокс: клик за пределами изображения или клавиша **Escape**.
- Миниатюры под главным изображением — переключение между фотографиями.

### Характеристики

Блок «Характеристики» показывает материал, вес и срок изготовления.

Блок «Доступные размеры» отображает все размеры, в которых изготавливается изделие.

### Связаться для заказа

Кнопка **Связаться для заказа** открывает диалог сообщества ВКонтакте для отправки запроса напрямую мастерской.

### Возврат в каталог

Кнопка **Назад в каталог** или ссылка «Каталог» в хлебных крошках возвращает к списку товаров с сохранёнными фильтрами.

## 3. Вход в панель мастерской

Кнопка входа расположена в правом верхнем углу (значок пользователя). Панель мастерской доступна только сотрудникам (`is_staff`).

После входа в шапке появляется меню с вкладками: **Каталог**, **Управление каталогом**, **Сводка**, **Заказы**, **Клиенты**, **Задачи**, **Допуски**.

---

## 4. Сводка

Вкладка **Сводка** — главный экран для руководителя мастерской.

### Счётчики заказов

Четыре плитки показывают количество заказов по статусам: Новый, В работе, Выполнен, Отменён.

### Горящие дедлайны

Список активных заказов со сроком сдачи в ближайшие 14 дней. Для каждого заказа отображается:
- Имя клиента и название предмета
- Дата дедлайна и количество дней до него
- Назначенный мастер

### Мало на складе

Предупреждения о материалах, остаток которых опустился до минимума или ниже. Показывает направление, текущий остаток, минимальный порог и единицу измерения.

---

## 5. Заказы

### Канбан-доска

Заказы представлены в виде четырёх колонок по статусам:

| Колонка | Значение |
|---------|----------|
| Новый | Заказ принят, работа не начата |
| В работе | Мастер приступил к изготовлению |
| Выполнен | Заказ завершён и сдан клиенту |
| Отменён | Заказ отменён |

Карточку можно перетащить между колонками мышью или нажать на кнопки смены статуса внутри карточки.

### Создание заказа

Кнопка **+ Новый заказ** открывает форму. Поля:

| Поле | Обязательно | Описание |
|------|-------------|----------|
| Имя клиента | Да | Ф.И.О. или никнейм |
| ВКонтакте клиента | Нет | Ссылка на профиль |
| Тип заказа | Да | Предмет / Комплект / Услуга |
| Предмет / Комплект | Нет | Выбор из каталога с автозаполнением цены |
| Дедлайн | Нет | Дата сдачи |
| Сумма | Да | Заполняется автоматически из цены товара |
| Аванс | Да | По умолчанию 50% от суммы |
| Назначить мастера | Нет | Один из сотрудников |
| Примечания | Нет | Свободный текст |

При выборе типа **Комплект** автоматически создаются задачи по каждому предмету в нём.

### Редактирование заказа

Клик на карточку открывает детальное представление с возможностью изменить любое поле.

Удалить заказ может только суперадмин.

## 6. Задачи

Задачи создаются автоматически при создании заказа. Вкладка **Задачи** делится на два раздела.

### Стек задач

Задачи, ожидающие исполнителя. Мастер видит **только те задачи**, к предметам которых у него есть допуск (см. [раздел 9](#9-допуски-мастеров)).

Кнопка **Взять задачу** переносит её в «Мои задачи» и назначает текущего пользователя исполнителем.

### Мои задачи

Задачи, которые мастер взял в работу. Действия:

- **Выполнено** — отметить задачу закрытой
- **Вернуть** — вернуть задачу обратно в стек (без удаления заказа)
- Добавить **примечание** к задаче

## 7. Клиенты

### Список клиентов

Поле поиска фильтрует список по имени. Для каждого клиента отображается:
- Статус (Потенциальный / Действующий / Завершён)
- Ссылка ВКонтакте
- Количество заказов
- Дата регистрации

### Редактирование клиента

Клик на строку открывает форму редактирования: имя, ВКонтакте, статус, примечания.

## 8. Управление каталогом

Вкладка доступна только сотрудникам (`is_staff`).

### Добавление товара

Кнопка **+ Добавить** открывает форму нового товара. Обязательные поля: название, категория, статус, материал, цена. Необязательные: подзаголовок, эпоха, вес, срок изготовления, историческая справка, описание, фотографии, бейдж.

### Редактирование товара

Кнопка карандаша на карточке товара открывает форму редактирования.

### Удаление товара

Кнопка корзины на карточке товара. Потребуется подтверждение.

### Отзывы

Отзывы оставляются посетителями из карточки товара в публичном каталоге. Управление через Django Admin (`/admin/`).

---

## 9. Допуски мастеров

Вкладка **Допуски** доступна только суперадминистратору.

### Принцип работы

Допуск — это связь «мастер + предмет». Мастер видит в стеке задач только те предметы, к которым у него есть допуск. Без допуска задача на изготовление шлема, например, не появится у кузнеца, специализирующегося на кожаных изделиях.

### Настройка

1. Выбрать мастера из списка сотрудников.
2. В правой части отметить галочками предметы, которые он может изготавливать.
3. Изменения сохраняются немедленно.

Суперадмин видит задачи всех мастеров и может взять любую задачу независимо от допусков.
