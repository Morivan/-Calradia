# ВВЕДЕНИЕ

Ремесленное производство исторического снаряжения — один из немногих видов деятельности, в котором ручной труд и глубокие специальные знания остаются абсолютно незаменимыми. Мастерская «Кузница Кальрадия» занимается изготовлением доспехов, шлемов, нагрудников, кольчуг и сопутствующего снаряжения, воспроизводя образцы западноевропейского вооружения XIII–XVI веков. Продукция ориентирована на участников клубов исторической реконструкции, ролевых игр, театральных коллективов и частных коллекционеров — людей, для которых важны не только функциональность изделия, но и его историческая достоверность.

Именно специфика аудитории и производственного процесса делают мастерскую совершенно непохожей на обычный интернет-магазин. Клиент не просто выбирает товар из готового ассортимента: он обсуждает с мастером исторический прообраз, материалы, размеры, степень украшения и сроки. Каждый заказ уникален или почти уникален. Над одним заказом могут работать несколько мастеров с разными специализациями: кузнец отвечает за металлические элементы, кожевник — за подшлемник и поддоспешник, специалист по клёпке — за кольчужные детали. При этом далеко не каждый мастер квалифицирован для работы с любым изделием.

До появления специализированного программного обеспечения мастерская решала эти задачи подручными средствами: записями в мессенджерах, таблицами Excel и общими папками в облачном хранилище. Такой подход неизбежно порождает проблемы: информация о заказах теряется при смене телефона, мастера не знают, чем занимаются коллеги, руководитель не видит полной картины загруженности. Публичная часть — портфолио мастерской — и вовсе отсутствовала: потенциальные клиенты не могли заранее познакомиться с изделиями, материалами, ценами и сроками изготовления.

Параллельно существовала и коммуникационная проблема: активная группа ВКонтакте публиковала фотографии готовых работ и новости мастерской, но эти материалы не попадали автоматически на сайт и не дублировались в Telegram — более популярном мессенджере среди молодой аудитории.

Настоящая выпускная квалификационная работа направлена на решение совокупности описанных проблем. Её результатом является полнофункциональное веб-приложение «Кузница Кальрадия», состоящее из двух неотделимых частей: публичного онлайн-каталога и производственной панели управления. Каталог даёт потенциальным клиентам полное представление об ассортименте, исторических основах изделий и условиях работы с мастерской. Панель управления — это внутренний инструмент, автоматизирующий приём заказов, распределение задач по специализациям мастеров, ведение клиентской базы и отслеживание дедлайнов.

**Цель работы** — спроектировать и реализовать веб-приложение, объединяющее публичный тематический каталог средневекового снаряжения с закрытой системой управления производством мастерской.

**Задачи работы:**

1) проанализировать предметную область мастерской и выявить проблемы, требующие автоматизации;
2) исследовать существующие программные решения, применимые в данной предметной области, оценить их пригодность;
3) сформулировать требования к разрабатываемой системе и составить техническое задание;
4) выбрать и обосновать архитектурные и технологические решения;
5) спроектировать структуру базы данных, REST API и пользовательский интерфейс;
6) реализовать серверную часть на Django 5 с Django REST Framework;
7) реализовать клиентскую часть — одностраничное приложение на React 19 с TypeScript;
8) реализовать интеграцию с ВКонтакте Callback API и Telegram Bot API для автоматической пересылки публикаций;
9) обеспечить защиту от основных категорий веб-угроз;
10) разработать автоматические тесты для API и бизнес-логики;
11) развернуть приложение на VPS-сервере в промышленной эксплуатации.

**Объект исследования** — производственно-коммерческая деятельность мастерской по изготовлению изделий исторической тематики.

**Предмет исследования** — методы и технологии разработки веб-приложений, совмещающих публичный каталог продукции с системой управления производственными процессами.

**Практическая значимость** работы состоит в том, что разработанная система находится в промышленной эксплуатации. Применение системы позволило сократить время на обработку нового заказа, ликвидировать потери информации при передаче задач между мастерами и обеспечить клиентам круглосуточный доступ к актуальному каталогу изделий.

Работа состоит из двух разделов, заключения, списка литературы и двух приложений с фрагментами исходного кода. Первый раздел посвящён теоретическому анализу предметной области, постановке задачи и проектированию системы. Второй раздел описывает практическую реализацию, тестирование и результаты работы.
