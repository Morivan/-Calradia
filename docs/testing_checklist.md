# Чек-лист тестирования «Кузница Кальрадия»

## Публичная часть

### Каталог
- [ ] Страница загружается, товары отображаются
- [ ] Фильтр по категории работает (показывает только нужные)
- [ ] Фильтр по периоду, материалу, наличию работает
- [ ] Поиск по названию работает (в т.ч. по подзаголовку)
- [ ] Сортировка: по дате, по популярности, по сроку
- [ ] Кнопка «Сбросить фильтры» появляется при активных фильтрах и сбрасывает всё
- [ ] Значок скидки отображается на товарах, входящих в комплект

### Карточка товара
- [ ] Открывается при клике на карточку
- [ ] Галерея: смена фото по клику на миниатюру
- [ ] Лайтбокс: открывается по клику на фото, навигация, закрытие через Esc и ×
- [ ] Характеристики, историческая справка отображаются
- [ ] Блок «Входит в комплект» отображается (если применимо)

### Комплекты
- [ ] Страница /sets открывается, список комплектов виден
- [ ] Зачёркнутая цена и цена со скидкой отображаются
- [ ] Переход на детальную страницу комплекта работает
- [ ] Из состава комплекта можно перейти на карточку товара

### Отзывы
- [ ] Список отзывов отображается
- [ ] Форма добавления отзыва отправляется
- [ ] После отправки отзыв появляется в списке без перезагрузки

### Адаптивность
- [ ] Каталог на мобильном (375px): одна колонка, фильтры сворачиваются
- [ ] Карточка товара на мобильном читается нормально

---

## Авторизация

- [ ] Страница /login открывается
- [ ] Неверный пароль — показывает ошибку
- [ ] Верный логин — редирект в панель
- [ ] После выхода (logout) панель недоступна, редирект на /login

---

## Производственная панель

### Сводка
- [ ] Счётчики заказов по статусам отображаются
- [ ] Список горящих заказов (дедлайн ≤14 дней) отображается

### Заказы (канбан)
- [ ] Карточки заказов видны в колонках по статусам
- [ ] Создание заказа: форма открывается, заполняется, сохраняется
- [ ] После создания автоматически появляются задачи (вкладка Задачи)
- [ ] Редактирование заказа работает
- [ ] Отмена заказа — только у руководителя

### Задачи
- [ ] Мастер без допуска **не может** взять задачу (ошибка)
- [ ] Мастер с допуском берёт задачу → она переходит в «В работе»
- [ ] Мастер отмечает задачу выполненной → статус заказа обновляется
- [ ] Мастер может вернуть задачу в стек

### Допуски (только руководитель)
- [ ] Таблица мастеров × направлений отображается
- [ ] Выдача допуска — мастер видит задачи нового направления
- [ ] Отзыв допуска — задачи этого направления исчезают из стека мастера

### Клиенты
- [ ] Список клиентов открывается
- [ ] Поиск по имени работает
- [ ] Создание клиента работает

---

## Безопасность

- [ ] Открыть /workshop без авторизации → редирект на /login
- [ ] POST /api/catalog/products/ без авторизации → 403
- [ ] Мастер не видит кнопку «Удалить заказ»
